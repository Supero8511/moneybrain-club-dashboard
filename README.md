# 머니브레인클럽 독서모임 대시보드

매월 진행하는 책을 포털에 나열하고, 책마다 **진도표 · 릴레이인증 · 서평인증**을 보여주는 대시보드입니다.
- 책별로 열람 권한을 어드민이 부여/회수할 수 있습니다.
- 운영진으로 지정된 멤버만 볼 수 있는 "인증사진/후기 자료실"이 책마다 따로 있습니다.
- GitHub Pages(정적 호스팅) + Firebase(로그인/데이터저장, 무료 플랜)로 동작합니다. 서버 비용이 들지 않습니다.

---

## 1. Firebase 프로젝트 만들기 (5분)

1. https://console.firebase.google.com 접속 → **프로젝트 추가** → 이름 입력(예: `moneybrain-club`) → 애널리틱스는 꺼도 됩니다 → 만들기.
2. 왼쪽 메뉴 **Authentication** → "시작하기" → **Sign-in method** 탭 → **이메일/비밀번호** 활성화.
3. 왼쪽 메뉴 **Firestore Database** → "데이터베이스 만들기" → 위치는 `asia-northeast3 (Seoul)` 추천 → **프로덕션 모드**로 시작(규칙은 아래에서 바로 교체합니다).
4. 왼쪽 메뉴 **Storage** → "시작하기" → 동일하게 진행.
5. 왼쪽 메뉴 **프로젝트 설정(톱니바퀴)** → **일반** 탭 → 맨 아래 "내 앱" → **웹 아이콘(`</>`)** 클릭 → 앱 닉네임 아무거나 입력 → 등록.
6. 화면에 나오는 `firebaseConfig` 객체 값을 복사해둡니다. (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)

## 2. 이 저장소에 Firebase 연결하기

`js/firebase-config.js` 파일을 열어 1번에서 복사한 값으로 교체하세요.

```js
export const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
export const SUPER_ADMIN_EMAIL = "idcrazyzz@gmail.com"; // 본인 이메일 (이미 설정됨)
```

> 이 파일을 수정한 뒤 GitHub에 커밋/푸시하면 사이트에 바로 반영됩니다.

## 3. 보안 규칙 적용하기 (중요 — 반드시 해야 함)

- Firebase 콘솔 → **Firestore Database** → **규칙** 탭 → 이 저장소의 `firestore.rules` 파일 내용을 전체 복사해서 붙여넣고 **게시**.
- Firebase 콘솔 → **Storage** → **규칙** 탭 → 이 저장소의 `storage.rules` 파일 내용을 전체 복사해서 붙여넣고 **게시**.

이 규칙이 실제로 "누가 어떤 책을 볼 수 있는지", "운영진만 자료실을 볼 수 있는지"를 서버 단에서 강제합니다. 앱 화면만 숨기는 게 아니라 데이터베이스 자체에서 차단합니다.

## 4. GitHub Pages로 배포하기

1. 이 저장소는 **Public(공개)** 이어야 무료로 GitHub Pages를 쓸 수 있습니다. (내용 자체는 로그인해야 보이므로 저장소가 공개여도 실제 데이터는 노출되지 않습니다.)
2. 저장소의 **Settings → Pages** → Source를 **Deploy from a branch**, Branch는 **main / (root)** 로 선택 → Save.
3. 1~2분 후 `https://<깃헙아이디>.github.io/<저장소이름>/` 주소로 접속하면 사이트가 열립니다.

## 5. 첫 로그인 & 초기 데이터 넣기

1. 배포된 사이트에서 **로그인/가입** → **회원가입** 탭 → 본인 이메일(`idcrazyzz@gmail.com`)로 가입합니다. `firebase-config.js`의 `SUPER_ADMIN_EMAIL`과 일치하면 자동으로 **어드민** 권한이 부여됩니다.
2. 주소창에 `.../seed.html` 을 입력해서 접속 → **"부의 갈림길 데이터 심기"** 버튼 클릭 → 10월 책의 진도표/릴레이 일정이 Google Sheet 내용 그대로 생성됩니다. (한 번만 누르세요. 다시 누르면 중복 생성됩니다.)
3. 관리자 페이지(`admin.html`)에서 운영진 멤버를 `staff` 역할로 지정하세요. (다른 운영진이 먼저 회원가입을 해야 역할 지정이 가능합니다.)

## 6. 멤버 초대 & 책별 권한 부여

1. 각 멤버에게 사이트 주소를 공유하고 **회원가입**(이메일 + 닉네임)을 안내하세요.
2. 회원가입이 끝나면 어드민/운영진이 `admin.html` → **"책별 열람 권한"** 카드에서 해당 책을 선택하고, 멤버 이름 옆 체크박스를 켜면 그 멤버가 책 페이지에 들어갈 수 있습니다. 체크를 끄면 즉시 접근이 막힙니다.
3. 운영진(staff)과 어드민(admin)은 권한 설정과 무관하게 모든 책에 항상 접근할 수 있습니다.

## 매달 반복하는 일

- `admin.html`에서 **"책 추가"** 로 새 책을 등록하면 포털 첫 화면에 바로 나타납니다.
- 책 페이지의 **진도표 / 릴레이인증** 탭에서 운영진이 주차/날짜 행을 추가하고 내용을 채웁니다.
- 멤버들은 로그인 후 본인이 담당한 릴레이 날짜의 글귀·느낀점을 직접 입력하고 완료 체크를 합니다.
- 서평인증 탭에서 멤버 각자 본인의 인증 링크를 입력합니다.
- 운영진은 "운영진 자료실" 탭에서 멤버 인증 사진/메모를 내부적으로 기록합니다. (운영진/어드민에게만 보임)

## 구조 / 기술 설명

```
index.html      포털(책 목록)
book.html       책 상세 (진도표 / 릴레이인증 / 서평인증 / 운영진 자료실)
admin.html      어드민 — 책 관리, 역할 관리, 책별 권한 관리
seed.html       최초 1회 데이터 입력용 (부의 갈림길)
js/common.js    Firebase 초기화, 로그인/가입, 헤더
js/data.js      Firestore/Storage 데이터 함수
firestore.rules Firestore 보안 규칙 (권한 제어의 핵심)
storage.rules   사진 업로드 보안 규칙
```

- 로그인/가입: Firebase Authentication (이메일/비밀번호)
- 데이터 저장: Firestore (책 목록, 진도표, 릴레이인증, 서평인증, 사용자 역할, 책별 권한)
- 사진 저장: Firebase Storage (운영진 자료실 인증사진, 책 표지)
- 비용: 소규모 독서모임 사용량에서는 Firebase 무료(Spark) 플랜 한도 내에서 충분히 운영 가능합니다.

## 문제 해결

- 사이트에 "⚠ Firebase 설정 필요"가 보이면 → `js/firebase-config.js`를 아직 실제 값으로 채우지 않은 것입니다.
- 로그인은 되는데 책이 전부 잠겨 보이면 → 어드민이 `admin.html`에서 아직 권한을 부여하지 않은 것입니다(정상 동작).
- 역할을 바꿔도 반영이 안 되면 → 로그아웃 후 다시 로그인해보세요.
