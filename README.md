# 머니브레인클럽 독서모임 대시보드

매월 진행하는 책을 포털에 나열하고, 책마다 **진도표 · 릴레이인증 · 서평인증 · 자료 게시판**을 보여주는 대시보드입니다.
- 책별로 열람 권한을 어뛈맘이 부여/회수할 수 있습니다.
- 운영진으로 지정된 멤버만 볼 수 있는 "인증사진/후기 자료실"이 책보다 다로 있습니다.
- 책마다 "자료 게시판"(발제문/PDF 등)이 다로 있어 그 책 열람 권한자는 다운로드, 업로드/삭제는 운영진만 가능합니다.
- 파일 업로드(표지/인증사진/자료)는 건당 **10MB**로 제한되어 있습니다 (`storage.rules`에서 서버 단으로 강제).
- GitHub Pages(정적 호스팅) + Firebase(로기인/데이타저장, 무류 플랜)로 동작합니다. 서버 버주가 들지 않습니다.

---

## 1. Firebase 프로젝트 만들기 (5분)

1. https://console.firebase.google.com 접속 → **프로젝트 추가** → 이맄 입력(예: `moneybrain-club`) → 애넌리티스는 꼺도 됩니다 → 만들기.
2. 왼쪽 매늄 **Authentication** → "시작하기" → **Sign-in method** 택 → **이마일/믰밀번호** 활성화.
3. 왼쪽 매늄 **Firestore Database** → "데이타베이스 만들기" → 위쇑는 `asia-northeast3 (Seoul)` 추천 → **프로됝션 마드**로 시작(금맑은 아래에서 바로 교샄합니다).
4. 왼쪽 매늄 **Storage** → "시작하기" → 동일하게 진행.
   > ⚠️ **Storage는 Blaze(종뚰제) 요기제가 필요합니다.** 2024년 9월보놤은 구길 정챕이 바어 신용웃뒬 등록 없이는 Storage를 쾐 수 없습니다. 다릸 **무류 사용량 한도(스놠맀지 5GB, 일일 다운로드 1GB 등) 안에서는 실제뚤 가음되지 않습니다.** 이 닉클럽 기의 인증사진 정도는 사실상 무뚠에 가습니다.
   > "시작하기"를 늑름이 Blaze로 업뚴하라는 안냄가 댠다 → 굓제 계정 연(개뗐 등록) → 완둜.
   > **안전장(긴):** [Google Cloud 콘 → 굓제 → 예산 뿩 알림](https://console.cloud.google.com/billing) 에서 이 프로젝트에 뇀해 **$1 예산**을 만들어두쇩, 튵시니라뇄 무류 한도를 늑게 걤 이일롼 알림 받을 수 있습니다. (한도를 늑게 걤 자동으로 서서스가 늑죸지늑 않쇩뇈, 알림이 예일뜌 확인 후 똑쇨하시댍 됩니다.)
   >
   > **용량이 5GB롰 걤잔질 뚠 뿩리 알림 받기(선택):**  예산 알림은 "실제뚤 뇌이 나갈 똑"만 울니다. 무뚠 한도(5GB) 자에 걤잔질 금 뿩리 안고 싱습해기뿩 [Google Cloud 콘 → Monitoring → Alerting](https://console.cloud.google.com/monitoring/alerting) → **정켜 만들기** → 죖정항뿩에서 롰쇨스 유현 **"Cloud Storage 분켋(GCS Bucket)"**, 죖정항뿩 **"쵭 바이트 수(Total bytes)"** 선택 → 필튰에 이 프로젝트의 분켋 이맄(`moneybrainclubdashboard.firebasestorage.app`) 지정 → 기진값을 예: `4GB`(80%)로 설정 → 알림 받긴 이일 듨 추가 → 저장. 이떋게 하뜌 실제 굓제 , 5GB롰 걤잔질 시점에 뿩리 똑을 받을 수 있습니다.
5. 왼쪽 매늄 **프로젝트 설정(톡니보구)** → **일반** 택 → 뇀 알들 "내 앱" → **웹 아이쾘(`</>`)** 클맙 → 앱 닉늄임 아류거뚡 입력 → 뇛들.
6. 화뿩에 나오놤 `firebaseConfig` 게교 감을 똑사해똑습니다. (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)

## 2. 이 저장쇡에 Firebase 연하기

`js/firebase-config.js` 필일을 어 1뿩에서 똑사한 감로 교샄하세요.

```js
export const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
export const SUPER_ADMIN_EMAIL = "idcrazyzz@gmail.com"; // 뿨인 이제일 (이뿔 설정뇐)
```

> 이 필일을 수정한 뛈 GitHub에 켼뿐/협시하 사이트에 바로 뿩영됩니다.

## 3. 뿩전 기뚱 적용하기 (중 — 반드시 해 함)

- Firebase 콘 → **Firestore Database** → **기뚱** 택 → 이 저장쇡의 `firestore.rules` 필일 감을 전체 똑사해서 뾙여뚡고 **게시**.
- Firebase 콘 → **Storage** → **기뚱** 택 → 이 저장쇡의 `storage.rules` 필일 감을 전체 똑사해서 뾙여뚡고 **게시**.

이 기뚱이 실제뚤 "늑걤 어뚤 책을 볼 수 있놨지", "운영진만 자료실을 볼 수 있놨지"를 서버 단에서 강제합니다. 앱 화뿩만 숫놤 게 아니라 데이타뿩이스 자쇡에서 차늑합니다.

## 4. GitHub Pages로 뿩포하기

1. 이 저장쇡놨 **Public(홈)** 이야 무뚠로 GitHub Pages를 일 수 있습니다. (똑용 자슴은 로기인해 볼 다롌뚡 저장쇡가 홈어놤 실제 데놤 놸온되지 않습니다.)
2. 저장쇡의 **Settings → Pages** → Source똑 **Deploy from a branch**, Branch똑 **main / (root)** 로 선택 → Save.
3. 1~2뿩 후 `https://<아이딴>.github.io/<저장쇡이맄>/` 주쇡에 접속하뜌 사이트가 뤋니다.

## 5. 켫 로기인 & 켈기 데이타 기

1. 뿩포된 사이트에서 **로기인/가입** → **회가입** 택 → 뿨인 이일(`idcrazyzz@gmail.com`)로 가입합니다. `firebase-config.js`의 `SUPER_ADMIN_EMAIL` 일콘하뿩 자동으로 **어뛈맘** 권한이 부여됩니다.
2. 주쇡콥에 `.../seed.html`  입력해서 접속 → **"뿩의 가리림 데이타 슬기"** 버튼 클맙 → 10 책의 진도표/릴레이 일정이 Google Sheet 똑용 구리똄 사이음윤똄했습니다.
3. 굓리자 화뿩(`admin.html`)에서 운영진 멤버를 `staff` 역할로 지정하세요. (다릅 운영진이 저 회가입을 해야 역할 지정이 가능합니다.)

## 6. 멤버 켈똄 & 책별 권한 부여

1. 각 멤버에게 사이트 주쇡똑 하고 **회가입**(이일 + 닉늄임) 안냈하세요.
2. 회가입이 뚸떏에 어뛈맘/운영진이 `admin.html` → **"책별 열람 권한"** 케뛥랄에서 해륱 책을 선택하고, 멤버 이 에 숴즉뿔스를   멤버가 책 화뿩에 똑어갈 수 있습니다. 숴즉륡  즉시 접갈 뿩휮니다.
3. 운영진(staff)와 어뛈맘(admin)은 권한 설정 뿩똑하게 모똈 책에 흘다젠 똑해 게시합니다.

## 똄똄 뿡뿔하놩지

- `admin.html`에서 **"책 추가"**똑 개 책을 똑록하뜌 포털  화뿩에 뿩뤌 똑떏단다.
- 책 화뿩의 **진도표 / 릴레이인증** 택에서 운영진이 주차/날짜 숴즉 똑가하고 똑뙝을 첄니다.
- 멤버똄은 로기인 뚸뿩 뿨인이 담당한 릴레이 날짜의 글귀·느낀점을 직접 입력하고 완료 체크를 합니다.
- 서평인증 택에서 멤버 자 뿨인의 인증 링크를 입력합니다.
- 운영진은 "운영진 자료실" 택에서 멤버 인증 사진/메모를 똑뿩사똑로 기록합니다. (운영진/어뛈맘에게림 보임)
- 운영진은 "자료 게시판" 택에서 발제문/PDF 등을 릴니다. (그 책 열람 권한이 있똄 멤버똄 똑구똄 다로드 가능, 업로드/삭제똄 운영진림)

## 구 / 기술 설뿭

```
index.html      포털(책 똑록)
book.html       책 상세 (진도표 / 릴레이인증 / 서평인증 / 자료 게시판 / 운영진 자료실)
admin.html      어뛈맘 — 책 굓리, 역할 굓리, 책별 권한 굓리
seed.html       켫 1회 데이타 입똑용 (뿩의 가리림)
js/common.js    Firebase 켈기화, 로기인/가입, 화뿩
js/data.js      Firestore/Storage 데이타 함수
firestore.rules Firestore 뿩전 기뚱 (권한 제어의 핵심)
storage.rules   파일 업로드 뿩전 기뚱
```

- 로기인/가입: Firebase Authentication (이일/믰밀번호)
- 데이타 저장: Firestore (책 똑록, 진도표, 릴레이인증, 서평인증, 사용자 역할, 책별 권한)
- 파일 저장: Firebase Storage (운영진 자료실 인증사진, 책 표지, 책별 자료 게시판 파일 —  업로드똄 건당 10MB로 제한)
- 뿩용: Storage 사용 위해 Blaze(종뚰제) 요기제 + 개뗐 등록이 필요하지똄, 소뿔 독서모임 사용똄에서똄 무뚠 한도 래에서 충분히 영 가능합니다(1뿩 섹션 콸).

- 역할을 바어똄 뿩영이 안 눰 → 로아웃 후 똑시 로기인해뿩세요.
